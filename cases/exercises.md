# Open exercises (no reference)

Texts without a reference model, written for StrataSQL. There is **no score and no hints**: the student models the text and reviews it with the Model check, the Physical view, the Sandbox and a list of questions (`src/data/exercises.ts`). Several answers can be right; the questions point at the decisions, not at one solution.

| Exercise | Difficulty | Practises |
|---|---|---|
| Car Rental | ★ | lookup entity (category price), history with own id, optional attribute |
| Gym | ★ | M:N with and without data, alternate identifier |
| Cinema | ★★ | dependent entity numbered in its parent (seat in hall), composite FK, rule as a key |
| Conference | ★★ | non-exclusive inheritance, ordered M:N, intermediate entity, rules outside the diagram |
| Airline | ★★★ | two links to the same entity (from / to airport), roles, dated flights, rules as keys |

Why no reference: writing a reference with tagged phrases, hints and a walkthrough is a full case (see the other files here). Exercises add variety cheaply; a good one can later be promoted to a full case.
